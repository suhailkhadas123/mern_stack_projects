## 🚀 How to Use

Clone the repository:

```bash id="clone-01"
git clone <repository-url>
```

Navigate into any task folder:

```bash id="cd-01"
cd JS/SuhailKhadass-task12
```

Open `index.html` or run React projects using:

```bash id="react-01"
npm install
npm start
```
